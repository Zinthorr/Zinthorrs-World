This GitHub version includes no built-in API key. To activate 3D Earth, 2D Maps, Search, 360° Street View, and GeoGuessr, save up to 5 Google Maps Platform API keys below (requires Map Tiles API and Places API (New)), or paste a key on line 4 of app.js. Keys are stored locally in your browser only (localStorage) and auto-failover if a key hits its daily cap.

Disclaimer: This is an experimental, AI-assisted hobby project built by an independent developer. On an unupgraded Google Cloud free-trial account, Google enforces locked daily caps (e.g., 15,000 Street View tiles/day) and automatically shuts off at the limit instead of charging you. Always restrict your key by HTTP referrer.
